1: Es la reutilización del código: se define la estructura (propiedades y métodos) una sola vez y se crean tantos objetos como se necesiten, sin repetir código

2: Porque this apunta siempre al objeto que está ejecutando el método en ese momento

3:Cuando el objeto conoce su propio estado lógico, los datos y la regla que depende de ellos quedan juntos en un solo lugar

4:el método cambiaría prestado a true sin verificar su valor actual, aunque el libro ya estuviera prestado

5: Permitir que el usuario ingrese los datos hace el programa flexible y reutilizable, el mismo código sirve para registrar cualquier vehículo sin tener que modificarlo ni volver a ejecutarlo
